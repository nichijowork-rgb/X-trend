# 配信番組サイト（/show/）仕様 v1

ダッシュボード（`/`）と同じサイト内に置く、週1回のニュース形式トーク配信用の「台本＋進行」サイト。決定事項はオーナー確定済み（2026-10-16）。

## 前提
- 配信: **毎週 土曜 1:00（JST）、約90分**。出演2人（読み手の割り振りは不要）。
- 事前確認: **前日（金）1:00 に下見、金 22:00 に最終確認**。
- 対象期間（番組週）: **前回配信（前週土 1:00）〜今回配信直前**。データの基準時刻は `posts.json` の `generated_at`（現在時刻ではない）。
- 置き場所: `/show/`（同一リポジトリ・GitHub Pages）。ダッシュボードとは**上部のページ切替タブ**（「ダッシュボード」「番組」）で行き来できる。
- データ: `data/posts.json`（全期間の投稿。番組週は ts で切り出す）、`data/reports.json`（weekly の的中率・見張り候補、答え合わせ）、任意 `data/bookmarks.json`（後述）。`data/` は読むだけ。
- 個人で集めた投稿: ①URLを手で貼る（複数行可）②Xのブックマーク（`data/bookmarks.json`。下記。ファイルが無い・壊れているときはブックマーク枠を非表示、他は動く）。手入力とブックマークで同じ id は 1 つに統合。
- **ブックマーク（2026-10-16 bot対応済み）**: 形式 `{ generated_at: "…+09:00", bookmarks: [{ id, url: "https://x.com/<user>/status/<id>", bookmarked_at: null | JST日時 }] }`。並びは新しくブックマークした順、毎日 0:23 ごろ更新。
  - `bookmarked_at` は「botが最初に見つけた時刻」（実際より最大1日遅れ）。10/16 より前からのものは null。
  - ブックマークした投稿は表示数が基準未満でも全件 posts.json に入り `in_bookmarks: true`（基準未満は `below_threshold: true` も）。id で posts.json を引いて本文・数値・メディア・カテゴリを表示する。
  - 数値は見つけた時点で固定（以後更新なし）→ カードに「数値はブックマーク時点」と注記。解除してもすぐ消えないことがある。
  - 編成画面の「★ブックマーク」枠: 既定は「bookmarked_at が番組週内」または「bookmarked_at が null で投稿日時（ts）が番組週内」。トグルで「すべて」も表示。過去の配信で読んだものは「使用済み」バッジを付けて下へ。
  - 今週分のブックマーク投稿は話題の自動まとめに含め、話題カードに「★ブックマーク n件」シール。話題性スコアに少し加点（1件ごと +10%、最大3件分）。
- 保存: 編成・メモ・アーカイブ状態・手入力URL・話題辞書は**ブラウザ内（localStorage）に自動保存**＋JSON 書き出し/読み込み。公開ファイルには書かない。

## 番組構成（既定・時間は編集可）
| 既定時間 | コーナー | 色 |
|---|---|---|
| 5分 | オープニング（タイトルコール・3大ニュース予告） | 白 |
| 35分 | メイン3トピック（各約11分） | 赤 |
| 5分 | 中休み（コメント・告知） | 白 |
| 25分 | カテゴリ別ニュース（ホスト／キャバクラ／歌舞伎町／夜職その他から選択） | ジャンル色 |
| 10分 | 雑談（一般のバズ） | クリーム |
| 5分 | 今週の答え合わせ（reports.json weekly） | グレー |
| 5分 | エンディング（まとめ・来週へ持ち越し） | 白 |

## 話題のまとめ方（類似投稿の統合）
1. **話題辞書**: `{ 話題名, ジャンル, 言葉[] , 関係者[]（店名・源氏名・@アカウント） }`。本文・matched_terms・ユーザー名に一致した投稿を同じ話題に。初期辞書例: 「ホストコール」← シャンパンコール/コール/ラスソン/マイク、など数件を用意。画面で追加・編集。
2. **自動提案**: 辞書に入らない投稿は本文の類似度（文字bigram等）＋同一アカウント・同一関係者でまとめ候補を作り「同じ話題かも？」として提示 → 採用/分割。
3. **手動**: 話題の結合・投稿の移動・話題名の変更。
- 話題ごとに 投稿数・合計インプレ・最大インプレ投稿・伸び（最大の伸びペース）を表示し、**話題性スコア**で並べる。メイン3本の候補は全ジャンルからスコア上位を提案。

## 画面
### ① 編成（準備）
- 番組週の表示、番組名（既定「週刊ヨルニュース」編集可）、**自動タイトル**「【番組名】話題A／話題B／話題C」（編集可）。
- ベントー（タイル）配置: 上段にメイン3枠（大・赤）、下にジャンル色の話題カード群。カードを各コーナーへ入れる・並べ替える（ボタン操作。ドラッグは任意）。
- 各ニュースの台本欄: 自動リード文（数字から下書き「今週◯◯が話題に。投稿△件、合計◯万インプレ」）、話すポイント、視聴者への質問。
- 個人投稿の追加（URL貼り付け）と「★ブックマーク」枠（上記）。
- **チェックポイント**: 「下見（金1:00）」「最終確認（金22:00）」で現在のデータ時刻を記録し、前回チェック以降に増えた投稿・話題に NEW を表示。
- 前週「来週に回す」にしたものを候補に表示。
### ② 進行（配信中）
- 現在コーナーの色を大きく使ったヘッダー、ニュース見出しを大きく。代表投稿（カード。必要なら埋め込み）、関連投稿、話すポイント。
- タイマー: 配信全体の経過／コーナー残り。押し・巻きを色で表示。開始ボタンで計測開始。
- 操作: 「読んだ」（済スタンプ→アーカイブ→次へ）、「飛ばす」「来週に回す」「戻す」。キーボード: →/Enter 読んだ、← 戻す、S 飛ばす、L 来週へ。
- サイドに番組全体の進行（済・現在・残り）。
### ③ 映す用（配信画面用）
- 別URL（`/show/#onair` 等）。自分用メモは出さない。コーナー切替時にジャンル色のタイトルカード、ニュース見出し＋代表投稿。進行画面の操作に追従（同じブラウザ内で BroadcastChannel/storage イベント連携）。OBS のブラウザソースで使える 1920×1080 想定。
### ④ 振り返り
- 読んだ／飛ばした／来週へ の一覧、台本のテキスト書き出し（告知・概要欄用）。

## デザイン
- 参考: POPでカラフルなベントー配置（黒背景、彩度の高い単色の角丸カード、極太の見出し、丸いシール風バッジ、スタンプ）。ダッシュボードはネオン調のまま、番組サイトだけPOP。

### データの読み方
- `../data/posts.json`・`reports.json`・`bookmarks.json` を `?t=` 付きで最初に 1 回だけ取得。posts が読めなければ `../sample/show/` を読み「サンプル表示中」の帯を出す（映す用は右上に小さく「サンプル」）。
- 番組週は `generated_at`（無ければ最新投稿）を含む「前週 土 1:00 以上〜土 1:00 未満」。ヘッダーで過去の週・来週（持ち越し確認用）に切り替えられる。
- matched_terms の `topic:` はデータ側の話題名としてそのまままとめる。`quote:` は外して言葉として使い、`report:` / `manual` / `inherit:` は使わない。

### 話題のまとめ方（順番）
1. 前週から持ち越した話題 → 2. `topic:` の話題名 → 3. 話題辞書（言葉は1点、関係者は2点。一番多く一致した項目。カタカナの言葉は前後がカタカナだと不一致＝「アルコール」は「コール」に入らない）
4. 残りから「同じ話題かも？」の提案: 本文の文字 bigram の類似（Jaccard 0.34 以上。多くの投稿に出る bigram は無視）→ 同じアカウント（夜職のみ）→ @で言及した相手（夜職のみ）。段階をまたいで鎖状につながらないようにしている。夜職と一般のバズは混ぜない。
5. 手動の上書き: 分割（バラす）・投稿の移動・話題の結合・名前・ジャンル。
- 話題性スコア = 合計表示 ＋ 最大伸びペース×12時間、投稿数で最大 +75%、★ブックマークで最大 +30%。表示数がすべて不明な話題は末尾。重みは `config.js` の `SCORE_WEIGHTS`。

- 話題 id: `d:<辞書id>` 辞書／`t:<話題名>` データ側の話題名／`c:<最古の投稿id>` 類似まとめ／`p:<投稿id>` 1件／`x:<投稿id>` データに無い個人追加（リンクだけ）／`k:<元の話題id>` 前週からの持ち越し／`m:…` 手動。

- チェックポイントは最新のものだけ投稿・話題の id 一覧を持ち、NEW は「その一覧に無いもの」。

### 使い方（オーナー向け）
1. **金 1:00（下見）**: `/show/` の［編成］で「下見（金1:00）を記録」。話題の候補から［メインへ］［カテゴリ別へ］［雑談へ］で入れる（メインは「おすすめで埋める」も可）。似た投稿は「同じ話題かも？」→［まとめる］か［バラす］。名前やまとめ先は［編集・台本］で。
2. 台本: 構成の各話題の「台本」を開き、リード文（自動の下書き）・話すポイント・視聴者への質問を書く。自分で見つけた投稿は URL を貼って［候補に追加］。
3. **金 22:00（最終確認）**: 「最終確認（金22:00）を記録」。下見以降に増えた投稿・話題に NEW が付く（データ更新後に見ると出る）。
4. **土 1:00 配信**: ［映す用↗］を別タブで開き OBS で取り込む。［進行］で「配信開始」→ →/Enter 読んだ、← 戻す、S 飛ばす、L 来週へ。映す用は自動で追従（同じブラウザのタブ同士）。
5. 配信後: ［振り返り］で「告知・概要欄用」をコピー。来週に回した話題は翌週の候補に「先週から持ち越し」で出る。
6. バックアップ・別PCへ: ［書き出し（JSON）］→ 別PCで［読み込み］。

### 注意・残課題
- 映す用の追従は**同じブラウザ内のタブ同士**だけ。OBS の「ブラウザソース」は別のブラウザなので追従しない → 映す用タブを開いたブラウザのウィンドウを OBS の「ウィンドウキャプチャ」で取り込む（ウィンドウを 1920×1080 にするか、OBS 側で切り抜き）。
- 見出しフォント（Dela Gothic One）は Google Fonts から読む。読めないときはシステムの太字。
- X 埋め込み・実画像は開発環境から X に接続できないため実機で確認が必要。
