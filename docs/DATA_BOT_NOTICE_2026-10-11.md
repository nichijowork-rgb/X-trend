# お知らせ：Xまとめの更新スケジュールとレポート内容の変更（10/11）

## 1. 更新回数：1日2回 → 1日1回
- 毎日 **23:59（JST）に1回**、その日の24時間分をまとめて更新します。初回は 10/11 23:59。
- 朝・夜の2回配信（朝5時・夜21時）は行いません。
- 週間まとめは変更なし：**毎週土曜 12:00**、直近7日分（保存したデイリー分をもとに作成）。初回は 10/17（土）。
- 画面への影響
  - 「最終更新」は1日1回しか変わりません。「次回更新：毎日23:59」などの表示があると親切です。
  - 「24時間」で絞り込むと、日中は前日23:59時点のデータになります。期間の基準は現在時刻ではなく**データの最新時刻**（generated_at または最新投稿）にしてください。

## 2. レポートのファイル名
- デイリー：`【Xデイリーまとめ】10月11日(sun)_2026年.md`
- 週間：`【X週間まとめ】10月10~17日_2026年.md`（日付は対象の7日間）
- 10/11 に出た「夕まとめ・試作」「週間まとめ・試作」は試作版です。今後の形式とは名前が違います。

## 3. デイリーまとめに追加される欄
- **伸びている投稿**（最大10件、夜職関連を優先）
  - 条件：投稿から2時間以内で15万表示以上、6時間以内で30万以上、12時間以内で40万以上のどれか
  - 1時間あたりの表示ペースが速い順に並べます（例：「投稿から3時間で38.2万表示、1時間あたり12.7万」）
  - 50万表示に届きそうな、伸び始めの投稿を早めに拾うための枠です。今後の表示回数を予想した数字は載せません。
- **答え合わせ**（初回は 10/12 23:59）
  - 前日に「伸びている」と載せた投稿のその後（例：「38.2万→62.5万、50万超え」）
  - 条件ごとに、何件中何件が50万を超えたか

## 4. 週間まとめに追加される欄
- 1週間分の「伸びている投稿」の的中率（条件ごと、ペース別）と、基準の見直し案
- 既存の「見張りアカウントの追加候補」はそのまま

## 5. 既存の構成（参考）
- 1. 夜職（ホスト / キャバクラ / 歌舞伎町 / 夜職その他）、2. 雑談に使える一般のバズ、（週間のみ）3. 見張りアカウントの追加候補
- 通常のまとめの対象は50万表示以上の投稿

## 6. データ（JSON）への影響
- posts.json / summary.json の項目は**変更なし**です。
- 「伸びている投稿」「答え合わせ」などのレポートの中身は、今のJSONには入っていません。画面に出す場合は、レポート用のデータ（reports.json）を別に用意します。必要なら相談してください。
- 基準の数字（15万/30万/40万など）は試行中なので、今後変わる可能性があります。画面に決め打ちしないでください。
