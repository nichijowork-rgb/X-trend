# 番組サイト v2 計画（2026-10-31 オーナー合意）

## 前提（オーナー回答）
- 台本ツールは **Windows の画面半分表示**（約 960×1040、2560 幅なら約 1280）で使うことが多い。
- OBS と台本ツールは**同じPC**。配信解像度 **1920×1080**。
- 既存ツール: コメント表示 = **CastCraft**、どね・スパチャ表示 = **Doneru（doneru.jp）**。これらと表示・機能が被らないこと（目標バー・コメント欄はこちらで作らない）。
- 収集ボット = **同じPC内の Grok ボット（デスクトップアプリ）**。リポジトリの data/ に push している。

## 段階
| 段階 | 内容 |
|---|---|
| 1 | 画面半分向けUI＋フォルダ型の台本づくり（D&D・新規まとまり・検索・ジャンル変更・元に戻す）＋一般のバズの絞り込み＋仕分けモード |
| 2 | OBS 用パーツ（トピック帯・投稿カード・コーナータイトル、透明背景・パーツ別URL）＋ OBS WebSocket（obs-websocket v5, ws://localhost:4455）経由で進行と連動 |
| 3 | Grok ボット連携（bot→サイト: 話題まとめ・雑談おすすめ `show_pick`・リード文下書き／サイト→bot: ジャンル修正・まとめ修正の書き戻し） |
| 4 | エフェクト（手動ボタン→ Doneru / CastCraft 連動の可否を調査して自動化） |

## 段階1 仕様
### 画面サイズ
- 基準幅は **960px（画面半分）**。1280px・全画面（1920）・スマホ（375）でも崩れない。全画面では余白が増える／3ペインになる程度。

### 編成画面 = フォルダ型（Finder 風）
- **左ペイン（約300〜340px）: フォルダツリー**
  - 番組構成: メイン1 / メイン2 / メイン3 / カテゴリ別ニュース / 雑談（一般のバズ）
  - まとまり（話題）: 夜職の話題一覧（ジャンル色）、一般のバズの話題一覧
  - 受信箱（未整理）: どのまとまりにも・番組構成にも入っていない今週の投稿
  - ★ブックマーク / NEW / 片付け / ゴミ箱
  - 各フォルダに件数。開閉可。
- **右ペイン: 選んだフォルダの中身**（コンパクトな行リスト: チェックボックス・ジャンル色・名前/本文1行・アカウント・インプレ・★）。行を選ぶとプレビュー（X埋め込み、失敗時は自前カード）を表示。960px ではリスト↔プレビューの切替（プレビュー上部に「← 一覧へ」）、1400px 以上ではツリー｜リスト｜プレビューの3列。
- **検索**: 上部に常設。本文・アカウント・話題名・matched_terms をスペース区切り AND で今週の全投稿から検索。結果も同じ行リストで、そのまま D&D／一括操作できる。
- **ドラッグ＆ドロップ**（マウス・タッチ両対応、pointer events で自作。HTML5 DnD に依存しない）
  - 投稿（複数可）→ まとまりフォルダ: 移動（元のまとまりから外れる）
  - 投稿 → 番組構成フォルダ: その投稿だけの「単発まとまり」として入る（既にまとまりに属していればそのまとまりごと）
  - まとまり → 番組構成フォルダ: 追加。番組構成内の並べ替えもドラッグ
  - 投稿／まとまり → ゴミ箱・片付け
  - ドロップ先のハイライト、ドラッグ中の件数バッジ、Esc でキャンセル
  - 代替操作: 「移動先…」メニュー（キーボードでも操作可）
- **複数選択**: Ctrl/⌘＋クリック、Shift＋クリック、チェックボックス、Ctrl+A（表示中のみ）。選択中は下部に一括操作バー（移動先… / まとまりにする / ジャンル変更 / 片付け / 削除）。
- **新規まとまり**: 「＋新しいまとまり」で空のフォルダ（名前・ジャンルを入力）。選択した投稿から「まとまりにする」でも作成。名前はダブルクリックかF2で変更。
- **ジャンル変更**: 投稿・まとまり単位で ホスト／キャバクラ／歌舞伎町／夜職その他／一般のバズ に上書き（右クリック・「…」・プレビュー・一括操作バー）。投稿の上書きは**投稿IDで保存し翌週以降も有効**。まとまりのジャンルは上書きがなければ中の投稿から決める。上書き一覧は段階3でボットへ返せる形式で保持（書き出しに含める）。
- **右クリックメニュー**: 上記操作をまとめて出す。
- **元に戻す / やり直す**: Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y）。D&D・移動・ジャンル変更・作成・名前変更・片付け・削除すべて対象。画面上の「元に戻す」ボタンも併設。
- 既存の 片付け／ゴミ箱、チェックポイント（NEW）、書き出し/読み込み、ブックマーク、カード/埋め込み切替、詳細ビュー相当（プレビュー）、メイン3は夜職のみ、は維持。保存データはスキーマ移行で引き継ぐ。

### 一般のバズの絞り込み
- 一般のバズは**既定で「おすすめ」だけ**表示（今週の上位 N 件、N は config で既定 30）。並びは話題性スコア（インプレの対数・伸び・★）。「すべて（n件）」に切替可。
- 将来ボットが付ける `show_pick: true`（雑談向けおすすめ）があれば、それを最優先で「おすすめ」に入れる（段階3の受け口だけ用意）。

### 仕分けモード
- 受信箱・検索結果・任意フォルダから開始。1件ずつ大きく表示（埋め込み）。
- キー: **1** メイン候補 / **2** カテゴリ別 / **3** 雑談 / **G** ジャンル変更（夜職⇄一般、またはメニュー）/ **X** いらない（片付け）/ **→** 保留して次 / **←** 前 / **Esc** 終了。各操作は元に戻せる。
- 「メイン候補」は番組構成の下の「メイン候補」フォルダ（メイン1〜3に入れる前の置き場）に入る。
- 進捗（n / 全件）と残り件数を表示。

### 進行画面（画面半分向け）
- 縦1列: 上に細い進行バー（コーナーと話題の済/現在/残り）＋現在の話題名（大）＋タイマー、中央に代表投稿、下にボタン固定（戻す/飛ばす/来週へ/読んだ）。
- 全画面時は右に一覧を出してよい。

### 段階2を見据えて
- 進行状態の変化（現在の話題・コーナー・投稿カードの表示/非表示）を1か所でイベントとして発行する作りにしておく（段階2で OBS WebSocket に流す）。
